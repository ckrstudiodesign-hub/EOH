Emerge on Horizon website (redesign by CKR Creatives)

HOW TO OPEN IT ON WINDOWS
1. Unzip this folder.
2. Double-click "Open website.bat".
3. Your browser opens the site at http://localhost:8080
   (keep the black window open; close it to stop).

Why not just double-click index.html? The 3D scenes and some animations
only work when the site runs from a small local server, which the .bat file starts.
It needs Node.js, which is already on your laptop.
